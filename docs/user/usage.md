# 安装与公式使用

先确认客户端进程位数；32 位客户端使用 x86，64 位客户端使用 x64。将 `TDXSegment.dll` 放入客户端允许的 DLL 目录，在公式管理器中绑定 DLL 槽位。具体菜单及目录由客户端版本决定，配图步骤见[用户首页](../../README.md#安装说明)。

所有随包公式默认第 1 槽 `TDXDLL1`，更换槽位时必须同步替换调用名。先加载 `01_DLL接口自检公式.txt`，确认最后一根 K 线的接线提示和端点回显，再使用 `02_通达信笔识别与正式线段公式.txt`。另外提供 `03_主图替换_待定区恢复K线版.txt` 与 `04_笔端点精准价格测试模式.txt`。

rc.2需同时更新DLL与四份日常公式，另外提供05迁移对照公式；各项差异数和加载错误应为0，详细步骤见[笔迁移说明](../development/pen-migration.md)。

函数 99 仅验证接线和输入；没有线段事件可以是合法待定。函数 1 为默认策略，函数 2 为实验策略，切换会改变算法行为。公式输入标记 1 为顶、-1 为底、0 为无端点；价格输入依次为 H、L。连续同类候选由内核折叠：顶取更高、底取更低，同价取较晚位置。

加载失败时检查位数、文件路径、绑定槽位和客户端实际加载的版本。显示输入错误时先用 01 自检公式定位诊断码。更新 DLL 前退出客户端并备份旧文件；不要仅凭文件名判断版本，应核对发布清单中的 SHA-256。

本次验收包含真实 Windows LoadLibrary/GetProcAddress 与注册回调测试。它不替代在具体通达信版本中导入公式、刷新和观察图形的人工验证；本版该人工验证未执行。
