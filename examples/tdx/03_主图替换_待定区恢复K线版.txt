{ ============================================================
  通达信笔识别 + 线段 DLL 接口 + 待定区恢复 K 线

  本公式用于“主图指标替换”场景：
    1. 已确认线段覆盖的历史区间始终画黄色线段，白色笔由注释开关控制；
    2. 最后一个已确认线段结构端点之后属于当前待定区，恢复原始 K 线；
    3. 待定区在原始 K 线上继续绘制白色笔，便于同时观察笔与未确认行情；
    4. 尚无任何已确认线段时，整个当前范围都显示原始 K 线；
    5. 最后一个已确认结构端点本身仍归入已确认区，从下一根 K 线开始恢复。

  已确认区白色笔开关位于“已确认区笔显示开关”一节：
    CLHISTPEN=1：已确认区显示白色笔，当前默认为此模式；
    CLHISTPEN=0：已确认区隐藏白色笔。
  两个赋值只允许一个处于注释外；切换时交换两行外侧的大括号注释。
  此开关不控制待定区；待定区在两种模式下都显示白色笔。

  DLL 输入固定为：
    参数 A = PENEVENT：1 顶端点，-1 底端点，0 非端点
    参数 B = H
    参数 C = L

  PENEVENT 描述顶/底端点，不直接描述笔方向。
  DLL 用相邻“底→顶”恢复向上笔，用相邻“顶→底”恢复向下笔。
  order 使用 DLL 数组的零基下标；position 对恢复后的笔连续编号。
  DLL 从左到右寻找最早满足线段基础定义的三笔窗口：三笔方向交替且
  具有公共重叠区间，第三笔不要求沿窗口方向相对第一笔创新高或创新低。
  该窗口第一笔的起点和方向就是初始线段锚点，不再把第 0 笔强定为起点。
  因此公式调用范围应尽量包含完整历史；更早数据可能使初始锚点前移。

  TDXDLL1 函数编号 1 的返回值是逐 K 线非负整数位掩码：
    bit 0，值   1：本 K 线是已确认向上线段的结构端点
    bit 1，值   2：本 K 线是已确认向下线段的结构端点
    bit 2，值   4：本 K 线发生向上线段确认事件
    bit 3，值   8：本 K 线发生向下线段确认事件
    bit 4，值  16：本 K 线是首条已确认向上线段的起点
    bit 5，值  32：本 K 线是首条已确认向下线段的起点
    bit 6，值  64：DLL 输入校验失败，仅允许出现在最后一根 K 线

  起点位只标识本次已确认线段链的第一起点；后续线段起点由前段端点给出。
  价格来源由方向唯一确定：向上段从 L 到 H，向下段从 H 到 L。
  H/L 还会在 DLL 内保留为逐 K 线只读路径：第一种情况用它定位冻结 C
  最后来源笔第一次严格跌破标准 B.low（向下镜像为升破标准 B.high）的
  确认 K 线；等号不算越界，确认位可能早于该来源笔的终点。
  对连续线段链，后一段确认位不得早于前一段；若后一段的独立结构
  证据更早，DLL 只把其对外确认位抬到前段确认 K 线，不改结构端点。
  ============================================================ }

{ ====== 笔识别：保持现有正确实现 ====== }
CLG:=MA(C,5);
CLD:=MA(C,10);
CLHH:=REF(H,5)=HHV(H,11);
CLLL:=REF(L,5)=LLV(L,11);
CLFG01:=BACKSET(CLHH,6)>BACKSET(CLHH,5);
CLFD01:=BACKSET(CLLL,6)>BACKSET(CLLL,5);
CLFG02:=IF(BARSLAST(CLFG01)=BARSLAST(CLFD01) AND CLG>CLD,CLFG01,IF(BARSLAST(CLFD01)>BARSLAST(CLFG01),CLFG01,0));
CLFD02:=IF(BARSLAST(CLFG01)=BARSLAST(CLFD01) AND CLD>CLG,CLFD01,IF(BARSLAST(CLFG01)>BARSLAST(CLFD01),CLFD01,0));
CLFG0:=CLFG02 AND H=HHV(H,BARSLAST(CLFD02));
CLFD0:=CLFD02 AND L=LLV(L,BARSLAST(CLFG02));

CLGQ:=L>REF(H,1) AND DAY!=REF(DAY,1);
CLDQ:=H<REF(L,1) AND DAY!=REF(DAY,1);

CLFGH:=REF(H,BARSLAST(CLFG0));
CLFGL:=REF(L,BARSLAST(CLFG0));
CLFGH1:=REF(H,BARSLAST(CLFG0)+1);
CLFGL1:=REF(L,BARSLAST(CLFG0)+1);
CLFGH2:=REF(H,BARSLAST(CLFG0)+2);
CLFGL2:=REF(L,BARSLAST(CLFG0)+2);
CLFDH:=REF(H,BARSLAST(CLFD0));
CLFDL:=REF(L,BARSLAST(CLFD0));
CLFDH1:=REF(H,BARSLAST(CLFD0)+1);
CLFDL1:=REF(L,BARSLAST(CLFD0)+1);
CLFDH2:=REF(H,BARSLAST(CLFD0)+2);
CLFDL2:=REF(L,BARSLAST(CLFD0)+2);

CLFGZH:=IF(CLFGL<=CLFGL1,CLFGH2,CLFGH1);
CLFGZL:=IF(CLFGH1<CLFGL,CLFGL,IF(CLFGL<=CLFGL1,CLFGL2,CLFGL1));
CLFDZH:=IF(CLFDL1>CLFDH,CLFDH,IF(CLFDH>=CLFDH1,CLFDH2,CLFDH1));
CLFDZL:=IF(CLFDH>=CLFDH1,CLFDL2,CLFDL1);
CLFG1:=CLFGH>CLFDZH AND CLFG0;
CLFD1:=CLFDL<CLFGZL AND CLFD0;
CLFG:=CLFG1 AND CLFGH>CLFDH AND CLFGL>CLFDL AND CLFGL1>CLFDL;
CLFD:=CLFD1 AND CLFDL<CLFGL AND CLFDH<CLFGH AND CLFDH1<CLFGH;

CLBH0:=(H<=REF(H,1) AND L>=REF(L,1)) OR (H>=REF(H,1) AND L<=REF(L,1));
CLBHG:=COUNT(CLBH0,BARSLAST(CLFD0));
CLBHD:=COUNT(CLBH0,BARSLAST(CLFG0));
CLBGQ:=COUNT(CLGQ,BARSLAST(CLFD0));
CLBDQ:=COUNT(CLDQ,BARSLAST(CLFG0));
CLBK0:=IF(CLBHG>0,CLBHG+2+1,IF(CLBHD,CLBHD+2+1,3));
CLBK:=IF(CLBGQ,CLBK0-CLBGQ,IF(CLBDQ,CLBK0-CLBDQ,CLBK0));

CLG1X:=(CLFG AND BARSLAST(CLFD)>CLBK);
CLD1X:=(CLFD AND BARSLAST(CLFG)>CLBK);
CLG1:=(CLFG0 AND REF(H,BARSLAST(CLFG0))>=REF(H,BARSLAST(CLG1X)) AND BARSLAST(CLD1X)>BARSLAST(CLG1X)) OR (CLFG1 AND COUNT(CLGQ,BARSLAST(CLFD1))>0 AND REF(H,BARSLAST(CLFG1))>REF(H,BARSLAST(CLG1X)));
CLD1:=(CLFD0 AND REF(L,BARSLAST(CLFD0))<=REF(L,BARSLAST(CLD1X)) AND BARSLAST(CLG1X)>BARSLAST(CLD1X)) OR (CLFD1 AND COUNT(CLDQ,BARSLAST(CLFG1))>0 AND REF(L,BARSLAST(CLFD1))<REF(H,BARSLAST(CLD1X)));

CLG1H:=IF(BARSLAST(CLD1)>BARSLAST(CLG1),REF(H,BARSLAST(CLG1)),REF(H,BARSLAST(CLD1)));
CLD1L:=IF(BARSLAST(CLG1)>BARSLAST(CLD1),REF(L,BARSLAST(CLD1)),REF(L,BARSLAST(CLG1)));
CLG2:=CLG1 AND H=HHV(CLG1H,BARSLAST(CLD1)+1) AND H>REF(H,1) AND BARSLAST(CLD1)>BARSLAST(CLG1);
CLD2:=CLD1 AND L=LLV(CLD1L,BARSLAST(CLG1)+1) AND L<REF(L,1) AND BARSLAST(CLG1)>BARSLAST(CLD1);

CLG3:=CLG2 OR (CLFG0 AND REF(H,BARSLAST(CLFG0))>REF(H,BARSLAST(CLG2)) AND BARSLAST(CLD2)>BARSLAST(CLG2));
CLD3:=CLD2 OR (CLFD0 AND REF(L,BARSLAST(CLFD0))<REF(L,BARSLAST(CLD2)) AND BARSLAST(CLG2)>BARSLAST(CLD2));

{ ====== DLL 输入 seam ====== }
CLG3SAFE:=IF(ISVALID(CLG3),CLG3,0);
CLD3SAFE:=IF(ISVALID(CLD3),CLD3,0);
CLPENEVENT:=IF(CLG3SAFE,1,IF(CLD3SAFE,-1,0));
CLSEGRAW:=TDXDLL1(1,CLPENEVENT,H,L);
CLSEGVALID:=ISVALID(CLSEGRAW);
CLSEGCODE:=INTPART(MAX(IF(CLSEGVALID,CLSEGRAW,0),0));

{ ====== DLL 输出位解析 ====== }
CLUPSEGEND:=MOD(INTPART(CLSEGCODE/1),2)=1;
CLDOWNSEGEND:=MOD(INTPART(CLSEGCODE/2),2)=1;
CLUPCONFIRM:=MOD(INTPART(CLSEGCODE/4),2)=1;
CLDOWNCONFIRM:=MOD(INTPART(CLSEGCODE/8),2)=1;
CLUPCHAINSTART:=MOD(INTPART(CLSEGCODE/16),2)=1;
CLDNCHAINSTART:=MOD(INTPART(CLSEGCODE/32),2)=1;
CLINPUTERROR:=MOD(INTPART(CLSEGCODE/64),2)=1;

{ ====== 可审计输出；可被其他公式按输出名引用 ====== }
PENEVENT:CLPENEVENT,NODRAW;
SEGEVENT:CLSEGCODE,NODRAW;

{ ====== 已确认区与待定区分界 ====== }
CLSEGPOINT:=CLUPSEGEND OR CLDOWNSEGEND;
CLHASSEG:=CONST(COUNT(CLSEGPOINT,0))>0;
CLTAILK:=IF(CLHASSEG,
            BACKSET(ISLASTBAR,BARSLAST(CLSEGPOINT)+1)
            AND (CLSEGPOINT=0),
            1);

{ 选择区————————————————————
====== 已确认区笔显示开关：CLHISTPEN=1 /0控制线段确定区的笔显示====== 
}
CLHISTPEN:=1;



{ 最后结构端点是待定反向笔的起点，隐藏历史笔时仍必须保留该点。 }
CLLASTPT:=BACKSET(ISLASTBAR,BARSLAST(CLSEGPOINT)+1)
          AND CLSEGPOINT;
CLPENAREA:=CLTAILK OR CLLASTPT OR CLHISTPEN;

{ ====== 待定区先绘制原始 K 线，笔和线段随后覆盖在上层 ====== }
CLKH:=IF(CLTAILK,H,DRAWNULL);
CLKO:=IF(CLTAILK,O,DRAWNULL);
CLKL:=IF(CLTAILK,L,DRAWNULL);
CLKC:=IF(CLTAILK,C,DRAWNULL);
DRAWKLINE(CLKH,CLKO,CLKL,CLKC);

{ ====== 按开关绘制历史笔；待定区始终同时显示 K 线和白色笔 ====== }
CLGP:=IF(CLG3 AND CLPENAREA,H,DRAWNULL);
CLDP:=IF(CLD3 AND CLPENAREA,L,DRAWNULL);
DRAWLINE(CLD3 AND CLPENAREA,L,
         CLG3 AND CLPENAREA,H,0),COLORWHITE;
DRAWLINE(CLG3 AND CLPENAREA,H,
         CLD3 AND CLPENAREA,L,0),COLORWHITE;

{ ====== 已确认线段可视化 ====== }
CLUPSEGSTART:=CLUPCHAINSTART OR CLDOWNSEGEND;
CLDOWNSEGSTART:=CLDNCHAINSTART OR CLUPSEGEND;
DRAWLINE(CLUPSEGSTART,L,CLUPSEGEND,H,0),COLORYELLOW,LINETHICK2;
DRAWLINE(CLDOWNSEGSTART,H,CLDOWNSEGEND,L,0),COLORYELLOW,LINETHICK2;

{ ====== 输入错误提示 ====== }
DRAWTEXT_FIX(ISLASTBAR AND CLINPUTERROR,0,0,0,'线段DLL输入错误'),COLORRED;
DRAWTEXT_FIX(ISLASTBAR AND CLSEGVALID=0,0,0,0,'线段DLL无有效返回：检查位数、路径和绑定槽位'),COLORRED;
